CASE 02 / CONTENT · IP · EDUCATION

李时珍项目

把专业知识变成受众能理解、能行动的内容。

OVERVIEW

围绕中医教育与大健康业务，连接人物信任、专业内容和课程招生。

我的角色
前期我负责创始人 IP 内容打造；后期担任总经理助理，参与 IP 商务合作与集团品牌运营。

01 / BACKGROUND

复杂业务需要被讲清楚

学校、专家、课程和线下业务各有信息。内容要让用户快速理解：谁值得信任、课程解决什么问题、下一步如何行动。

02 / CONTENT SYSTEM

三条主线

01

专业翻译

我把专业内容转化为用户能理解的短视频与图文表达。

02

人物信任

我围绕创始人和校长的身份、经历与观点组织 IP 内容。

03

课程连接

我参与把内容与课程价值、招生咨询和商务合作连接起来。

COMPLEX BUSINESS→CONTENT TRANSLATION→TRUST→CONVERSION

03 / MY CONTRIBUTION

我负责的工作

前期，我负责李时珍创始人 IP 的内容打造。后期，我参与 IP 商务合作、谈判与合作方案，并参与集团品牌故事、品牌手册、品牌形象和公众号等工作。我的工作从账号内容逐步扩展到品牌与业务表达。

04 / PROJECT RESULTS

项目阶段结果

近 20 万校长 IP 全平台粉丝项目阶段结果
2 万+单条内容带来的涨粉项目阶段结果
500+单日客资峰值项目阶段结果

05 / EVIDENCE

代表内容

06 / LESSON

让专业内容服务用户行动

这段经历让我意识到，专业内容的价值在于让用户理解：为什么信任这个人、课程与自己有什么关系、下一步该做什么。
