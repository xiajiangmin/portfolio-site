02 / 中医教育与大健康

李时珍项目

从创始人 IP 内容运营，逐步进入课程招生、集团品牌与商务合作。

项目介绍

这是一个同时包含中医教育、课程招生与大健康业务的长期项目。
我的角色前期负责创始人 IP 内容运营；后期转入总经理助理角色，继续参与 IP 商务合作、合作方案与集团品牌相关工作。

01 / 项目是什么

一个同时连接人物、课程和品牌的内容项目

项目以中医教育业务为基础，同时涉及专家课程、招生、大健康业务和品牌建设。早期工作重点是把校长 / 创始人的专业经历、观点和业务内容持续做成可传播的 IP 内容；随着项目推进，我的工作逐渐从单一账号运营扩展到品牌与业务协同。

02 / 我的工作

从创始人 IP，做到品牌与商务协同

01

创始人 IP 内容运营

负责内容选题、脚本与表达，把人物经历、行业观点、学校业务和课程内容持续转成账号内容。

02

课程与招生内容

围绕课程、专家与用户关心的问题组织内容，让账号增长能够继续连接咨询、招生和业务沟通。

03

集团品牌运营

参与品牌故事、品牌手册、品牌形象、文化墙、Logo、公众号等品牌内容与对外表达工作。

04

IP 商务合作

后期参与 IP 商务合作、合作谈判与方案制作，协助把内容影响力继续连接到外部合作。

05

业务方案支持

参与项目提案与合作方案，把项目背景、资源、业务价值和执行方式整理成对外可沟通的方案。

06

大健康产品协同

参与集团养生产品相关工作，让内容、品牌与后续产品方向形成更完整的业务连接。

03 / 项目结果

账号增长与招生结果

近 20 万校长 IP 全平台粉丝
2 万+单条内容带来的涨粉
500+单日客资峰值

这些结果来自项目阶段性运营表现；我主要负责前期创始人 IP 内容运营，并在后期继续参与品牌与业务协同。
