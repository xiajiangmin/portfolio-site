CASE 03 / IP · CONTENT · GROWTH

荟品仓

把人物、内容与门店放进同一个增长系统。

OVERVIEW

仓储式奥莱有创始人、员工、商品和门店活动等内容来源。内容既要建立品牌认知，也要给用户真实的到店理由。

我的角色
我担任新媒体运营负责人。

01 / BACKGROUND

线下场景如何变成线上内容

持续发视频并不足以解释品牌价值。人物建立信任，门店内容展示真实消费场景，本地达人帮助附近用户发现门店。

02 / STRATEGY

内容系统的三个部分

01

创始人 IP

我围绕创始人的经营经历和现实业务问题组织选题，完成脚本、拍摄剪辑与账号运营。

02

门店内容

我把门店员工、商品、活动和直播场景转成持续可拍的内容，并培训门店人员运营短视频。

03

本地达人

我参与 KOC 探店与信息流投放，让线上内容连接本地到店场景。

03 / MY CONTRIBUTION

我的动作与产物

我负责创始人 IP 的账号定位、脚本创作、拍摄剪辑和日常运营；同时负责门店微信公众号运营，参与选题、选品会议，审核文案与排版，并推进海报创意、门店活动及短视频培训。

04 / PROJECT RESULTS

项目阶段结果

6 万+创始人 IP 阶段粉丝项目阶段结果
729 万创始人 IP 累计曝光项目阶段结果
151 条本地达人投放视频项目阶段结果
1699 万达人视频累计曝光项目阶段结果

创始人 IP 直播在约三个月内实现超过 400 万元流水。

05 / EVIDENCE

代表内容

06 / LESSON

内容需要回答三个问题

这段工作让我更清楚地看到：本地零售内容要同时回答谁值得关注、为什么值得到店，以及什么内容能够持续生产。
